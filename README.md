# 行李規劃

手機瀏覽器用的行李重量規劃小工具，介面為繁體中文。純 HTML／CSS／JavaScript，不需後端，資料存在瀏覽器的 localStorage。

## 網址

https://mop0723-ai.github.io/luggage-app/

推送到 `main` 分支後，GitHub Actions 會自動發布到 GitHub Pages（設定檔在 `.github/workflows/pages.yml`）。

## 功能（第一版）

- **首頁**：大字顯示「剩餘可購物公斤數」（各行李上限總和 − 目前總重）。
  剩餘 ≥ 20% 為綠色（充裕）、0–20% 為黃色（快滿了）、超過上限為紅色（超重）。
  下方顯示目前總重量、各行李重量與物品清單。
  「行李額度」可依每次航空公司的額度調整各行李上限（預設托運 23 kg、登機 7 kg）、空箱重與名稱。
- **放進行李**：名稱、重量（kg 或 g）、數量、單位（個／包）、品類、放在哪個行李。
  七大品類：①必備品 ②保健品 ③保養品 ④特殊類 ⑤禮物 ⑥食品 ⑦電線電器。
  新增過的物品會自動記住，之後在「常帶物品」點一下即可帶入；可按「管理」刪除記錄。
- **常見物品參考重量**：輸入名稱時，如果對到參考重量表，會自動帶入大約重量並標示「約」。
  改成實際秤到的重量後，會以你的數字為準並記進常帶物品。

- **物品照片**：「放進行李」可拍照或從相簿選照片（可略過）。照片縮到最長邊 600 像素、
  JPEG 品質 0.7（太大會再降），每張盡量在 100KB 內，存在瀏覽器的 IndexedDB（`photos.js`）。
- **衣服標籤**：品類是「必備品」時，可點選衣服種類（大類→細項）、顏色、花紋、季節、風格，品牌自行輸入（`clothing.js`）。
  每件有照片或標籤的衣服都是獨立的常帶物品，常帶物品會顯示小縮圖。
- **我的衣櫃**：照片格子排列所有有標籤的衣服，依上衣、下身、洋裝、外套、鞋子、配件分頁，
  再依顏色、季節、風格篩選；可一鍵放進行李（`closet.js`）。

- **行程設定**：建立旅程（名稱、出發地），每趟可加多段航班（出發／抵達城市、日期、航班號碼、航空公司），
  每段有自己的托運、手提、背包額度；可編輯、刪除、調整順序。抵達有家的城市會標示「有家」（`trips.js`）。
  首頁的剩餘公斤數依「今天以後最近的一段航班」的額度計算，沒有行程時用「行李額度」的設定。
- **轉機資訊**：每段航班有起飛／抵達日期與時間（當地，點選 24 小時制時間選擇器），兩段之間自動算出轉機時間（跨日也正確）；
  每個轉機點可設定行李「直掛／領出」與「不入境轉機／入境停留」（可填停留天數、備註），列表以小標籤顯示。
- **物品位置**：衣物的位置分為「在某個家／在行李裡（記得行李箱與從哪個家帶出）／待確認」，並保留移動紀錄。
  行程抵達有家的城市（或旅程結束回家）時跳出「整理行李」，決定留下或帶走、從這個家的衣櫃挑東西帶走（`organize.js`）。
  衣櫃可手動「移到另一個家」，家的篩選有「在行李裡」分頁。
- **打包清單**：選一趟旅程自動產生清單（依目的地季節、活動、常帶物品，並固定提醒護照、錢包、充電線、睡衣），
  分手提／托運／背包三區，可打勾、拖曳換區、刪除、手動新增；顯示進度與各區重量對比額度；
  目的地的家已有的物品列在「家裡已經有，不用帶」；有「出發前檢查」。打勾＝放進行李，首頁重量同步（`packing.js`）。
- **我的抽屜**：衣服以外的物品（必備品、保健品、保養品、特殊類、禮物、食品、電線電器），依家切換、依品類分組，
  數量用加減按鈕或「有／快用完／沒了」；快速新增會帶入參考重量與品類，同一個家已有同名物品會提醒。
  抽屜物品和衣物一樣有位置（在某個家／在行李裡／待確認），整理行李畫面也包含抽屜物品（`drawer.js`）。
- **年度行事曆**：行程頁可切換「列表／月曆／年度時間軸」。月曆與年度色條顯示每趟旅程的日期區間；
  兩趟之間的空檔顯示回到哪個家、待幾天。每趟可設定「最後一段結束後回到哪個家」，新增下一趟時預設從那個家出發。

- **我的行李箱**（打包 → 我的行李箱）：名稱、類型（托運／手提／背包）、尺寸、款式、材質、空箱重量、放在哪個家、照片。
  箱子裡有東西＝跟著旅程出門，空的＝在它的家。打包清單從這裡挑箱子（出發地的家排前面），空箱重量自動算進去；
  抵達有家的城市整理行李時可以「換行李箱」，舊箱子留在那個家（`bags.js`）。
- **回程購物・送禮**（首頁剩餘公斤數下方、或「＋」→ 記一筆購物）：計畫購物／衝動購物比例滑桿、買之前試算、
  記錄購物（重量、價格、放進哪個行李、在哪個城市買、之後放到哪個家）；計畫清單打勾就記成已買。
  送禮：送給誰、在哪個城市送、想買／已買好／在行李裡／已送出，可從抽屜「禮物」品類挑；想買的禮物重量預留在計畫購物；
  抵達那個城市時首頁提醒「這裡有 X 份禮物要送」；可依送禮對象查看紀錄。放進行李的購物和禮物會算進首頁剩餘公斤數（`shop.js`）。
首頁「備份與雲端同步」可匯出／匯入備份檔（含所有資料與照片）（`backup.js`）。
- **雲端同步（Supabase）**：Email＋密碼登入；資料存在 `app_state` 資料表（每人一筆），照片存在 Storage 的 `photos`
  bucket（`<帳號 id>/<照片 id>.jpg`），以 Row Level Security 限制只能存取自己的資料（`cloud.js`）。
  資料先存在本機，有網路時自動同步；兩台裝置都改過時以上次同步內容為基準逐筆合併。
  程式只使用 publishable（公開）金鑰，不含 service_role 金鑰。Supabase 程式庫放在 `vendor/supabase.js`（v2.117.3）。
- **離線使用**：`sw.js`（Service Worker）快取 app 檔案，沒有網路也能打開。

## Supabase 設定

1. 在 Supabase 的 SQL Editor 執行 `supabase/setup.sql`（建立資料表與 RLS 規則，可重複執行）。
   再執行 `supabase/item-photos.sql`（建立私人照片空間 item-photos 與安全規則）。
2. Authentication → Sign In / Providers：確認 Email 已開啟。
3. Authentication → URL Configuration：Site URL 設為 `https://mop0723-ai.github.io/luggage-app/`。

## 介面

- 風格：米白底（#FAF7F2）＋深海軍藍（#0B1F3A）文字，香檳金（#C9A45C）只用在剩餘公斤數與中間的「＋」；
  標題用思源宋體、內文用思源黑體（Google Fonts，離線時改用系統字體）；細線分隔、不用色塊與陰影。
- 底部導覽五格：首頁／行程／「＋」（放進行李、新增衣服、新增抽屜物品、記一筆購物）／打包（含放進行李頁）／
  我的家（我的衣櫃、我的抽屜）（`nav.js`）。
- 首頁「我的行李」：每個行李一行，點開依品類列出物品，可打勾、移到別的行李、拿出來、放進更多東西。

## 資料結構

說明寫在 `app.js` 開頭。重點：
- `memory`（常帶物品）是「我擁有的東西」，每筆有 `photoId`、`clothing`（衣服標籤），
  並預留 `cloudId`、`syncedAt`（雲端儲存）與 `ai`（AI 辨識結果）。
- `clothing.part` 是穿搭部位（top、bottom、full、outer、shoes、accessory），給之後的模擬穿搭用；
  `outfits` 是預留的穿搭清單。
- 上一版衣櫃資料會自動轉進 `memory`，原始資料保留在 `legacyWardrobe`。
- `trips`（旅程）與航班段 `legs`，預留匯入訂位紀錄（`source`、`importRef`、`bookingCode`）、
  AI 辨識行程單（`ai`）與多人共用（`ownerId`、`members`、`shareCode`）的欄位。
- 行李的 `kind`（托運、手提、背包）對應航班的三種額度。
